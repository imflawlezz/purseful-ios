# Internationalization (i18n)

Purseful uses Xcode **String Catalogs** (`.xcstrings`). English is the source language.

## Catalogs

| File | Target |
|------|--------|
| `purseful-ios/Localizable.xcstrings` | App |
| `PursefulWidgets/Localizable.xcstrings` | Widgets |

English key list (one per line): [`l10n-english-keys.txt`](l10n-english-keys.txt).

## Languages

| Code | Language |
|------|----------|
| `en` | English (source) |
| `pl` | Polish |
| `ru` | Russian |
| `uk` | Ukrainian |
| `de` | German |
| `es` | Spanish |
| `fr` | French |

Edit translations in Xcode’s String Catalog editor (or the `.xcstrings` JSON).

## Conventions

- UI literals (`Text("Settings")`, `String(localized:)`) use the English string as the catalog key.
- Stored system names (categories, matching budget titles) display via `localizedDisplayName`.
- `field.type` is the key for the “Type” label (English value: `Type`).
- Version strings keep the word **Build** in English in every locale.
- Month headers use `LLLL yyyy` (standalone month), not `MMMM`.
- Do not localize SF Symbol names, URLs, App Group IDs, or user-entered text.

## Adding a language

1. Add every key to both catalogs (and `l10n-english-keys.txt` if new).
2. Translate with placeholders (`%@`, `%lld`, `%1$@`, `%2$@`, `%%`) preserved.
3. Register the region in the Xcode project if needed.
4. Verify on device with per-app language.
